# ADR-001 — Isolated, local-first FLOOR AI Lab

Status: accepted for prototype only, 2026-11-13. Base main: `ad985366b0cf65084523d876f66ca5dedcb68941`.
Read issues #261, #253, #255, #257, #258, #259 before edits. Open PRs reviewed: #252, #251 (dependencies), #240 (authority), #235 (catch-up), #185 (replay gaps), #184 (champion migration). None is assumed merged.

## Decision
Use the maintained official Python MCP SDK (pinned 1.30.0 stable v1 API), stdio and loopback Streamable HTTP, a separate SQLite transactional job/outbox store on an operator-owned persistent volume, a separately supervised worker, registered deterministic recipes, MLflow SQLite on demand (no tracking daemon), JSON/HTML reports, and Slack Web API. No workflows, schedules, official releases, production stores, champions or trading flags are changed.

Research is not official execution. Runtime Release archives are read-only inputs; validate SHA sidecar and copy only allowlisted files to research storage. Market observations fetched today are retrospective, not vintage point-in-time evidence. A content hash alone does not prove PIT correctness. Existing `available_at` absence must not be silently repaired.

Start with local execution: no cloud billing or public deployment. The operator must run worker and MCP independently of the client. An accepted SQLite queue persists when MCP exits; a Work process is NOT durable hosting. No claim of remote availability or Slack delivery until independently verified. Remote public access is blocked pending approved HTTPS/OAuth deployment. Private authenticated tunnel can forward loopback HTTP without rewriting MCP.

## Reuse
`models.temporal_cv.purged_expanding_folds` for whole-date purged folds; `features.feature_registry` for catalog; `features.feature_builder` and `features.labels` for reproducible source transforms; `models.classic_horizon_predictor` for frozen classic heads; existing replay/backtest/cost services remain authority for future adapters. Avoid cloning EOD/league business logic.

Recipes admit parameter schemas, not code/shell/SQL. Novel VIX/code proposals return approval-required specification until a reviewed adapter and PIT data contract exist. No training on arbitrary URLs or user-selected files through MCP. Dataset import is an operator action into a hash-addressed store.

## Consequences
Local host must remain on; SQLite volume requires backup. Single active worker conservatively bounds concurrency; child process resource/time caps apply. Ephemeral Actions alone cannot own queue/outbox: durable external state needs a separately reviewed adapter. Therefore initial Actions option is deferred, not misrepresented as implemented. MLflow records experiments, not queue/auth/notification state. Reports cannot promise financial significance from an exploratory ranking.
