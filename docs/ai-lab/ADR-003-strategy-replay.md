# ADR-003 — Reuse the Strategy League engine in isolated research

Status: prototype implementation, 2026-11-13. Integration baseline after authorized merges #262–#265: `cdeea810ce9ed0a090a2e7413389e4b8c5cbd8c6`.

The generic portfolio backtester sizes using close even with OPEN fills. The existing **league engine** already has the required contract: pending targets determined after t CLOSE, execution and sizing using t+1 OPEN, gap-aware stops with conservative stop-first daily ambiguity, temporal exits, costs, closing NAV, and append-only hash-chained audit. Reuse this engine and the existing strategy generators/target translators for `mean_reversion_floor_w1` and `breakout_protected_by_floor`; do not patch or fork financial logic.

The new registered recipe writes only within the accepted job's research directory. A research-only genesis starts with cash; benchmark SPY/equal-weight entries use the same first next-open opportunity and canonical fees/slippage. End-of-window liquidation at the last close is explicit for all participants. All capital, orders and fills are simulated; PAPER/LIVE broker flags remain false. No production ledger, Release, schedule, active strategy or champion is modified.

Each session has two audit phases: existing `advance_league` consumes previously pending targets and applies exits/marks; then the adapter computes new signals with only that session's completed inputs and the **updated** holdings, sets next-open targets and appends a `RESEARCH_DECISION` record using the engine's hash-chain writer. This avoids using pre-exit holdings for HOLD retention or today's close for today's opening allocation. Final liquidation adds a separate immutable research event, not another market session.

Forecasts use the existing `generate_forecasts` pipeline and all five frozen champion artifacts, including its M3 timing abstention. Strategy inputs exclude all labels/realizations. Liquidity/strategy features reuse `league.market_features._feature_row`; costs/risk use authoritative config hydration. Cost drift between league execution and research strategy profiles blocks. 61bps round-trip is the current observed profile, not a hardcoded substitute for the contract.

Scope is frozen-policy, long-only, retrospective reconstructed diagnostics, with no verified training/selection cutoff or historical AI-input vintages. No claim of official league parity, prospective performance, canonical bidirectional promotion or statistically established alpha. Missing bars/features/benchmarks, changed artifacts, unknown model timestamps, and attempts to enable broker execution fail closed. New strategies, cost stress, alternative model suites, and changed risk limits require a reviewed adapter/plan rather than arbitrary code or configuration paths.
